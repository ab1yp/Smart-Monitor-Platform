03 · Telemetry

Configuration and measurements stay separate.

Device identity belongs to the device document. Time-series readings are stored in dedicated collections using deviceId and timestamp, while the latest operational state is exposed through a compact status snapshot.

04 · Access control

Authorization is enforced on the server, not only in the UI.

Each device can have multiple members with owner, admin, or member access. Protected routes verify the authenticated user before device operations are allowed.

Owner

Full device control and membership management.

Admin

Operational access with elevated membership permissions.

Member

Standard access to the device workspace.
